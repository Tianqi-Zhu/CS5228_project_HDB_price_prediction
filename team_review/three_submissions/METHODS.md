# 方法对照与报告主线

## 1. 历史特征主融合：415.86912

以房屋、日期、位置和所给静态辅助信息为基础，构造楼栋/街道/区域与户型的过去租金统计、相对市场价格以及12/24/36个月同期历史统计。历史特征只查已知历史，验证时在预测原点冻结；没有用公开目标租金匹配复原答案。

组合LightGBM、CatBoost、XGBoost和FT-Transformer等10个已训练成员；不同成员预测原始租金、市场相对比例或历史基准残差，先还原为SGD租金后融合。它是三份提交中的强基线。

## 2. 宏观增强：415.78232

在历史主融合上加入使用比赛所给预测月份COE/股票信息的CatBoost，权重为历史版0.8673768172、宏观模型0.1326231828。这是额外给定信息条件的消融，不宣称真实部署时已知未来宏观观测。它只小幅改善Kaggle显示分数，本地年度并未改善。

## 3. 结构融合：415.37529，推荐final

保留原历史成员，另加入删去稀疏36月历史字段的FT四种子平均，以及PLR周期数值嵌入FT（128维、3个注意力块）。最终为12路预测，其中1路为4个FT种子的均值，底层15个预测器；不把15个预测器称为15种架构。

按24月/36月同期历史是否存在分最多四组。拟合融合权重时减去训练样本当月误差均值，权重非负、和为1、单路最高0.6；全局权重向原融合收缩，各组向全局收缩，正则均0.003；小于500个拟合样本的组及未知组回退到全局。预测时直接加权，不读取查询真实租金。

所有基础模型用提供的150,000条训练标签拟合；最终融合权重来自截至2025-03的53,135条历史样本外预测。没有使用测试标签、外部租金答案回填或手工修改预测来追分。

## 4. 报告怎样从基础讲到final

建议以“信息构造→模型利用→互补融合”为主线：

1. 定义月租预测、RMSE、训练/验证月份，说明过去租金特征的时间截止。
2. 用同27列输入对照Ridge、树模型、MLP和FT，检验模型差别。
3. 固定CatBoost/LightGBM设置，对照19→27→47→62列，解释普通历史与同期历史的增量。对应表在 `evidence/report_selection/controlled_feature_ladder.csv`。
4. 将原始租金、相对市场价格、残差视角组合，建立历史强基线。
5. 检验历史覆盖差异、分组收缩融合及数值嵌入，保留未改善的结构对照。
6. 用本页三份完整管线及准确Kaggle分数选final；把宏观版作为辅助信息消融。

三份提交之间有多个变化，不能把全部0.49383的Kaggle提升归因于PLR。固定第九轮融合规则后，单独增加PLR的本地近期变化为441.9591→441.8345，但年度450.8650→451.0295略退步。说明互补贡献有限且依赖窗口，不能声称复杂网络普遍优于树模型。

本地各窗口被反复筛选、最终也参考了三份提交分数，结果不属于独立盲测。报告保留这一选择口径，且不将他人约170分的方法纳入正常预测对照。
