## 低成本分析的核心观察

- J 的 F2−F1 RMSE 为 −0.882577 SGD。3个月移动区块的 95% 描述区间为约 [−1.192674, −0.485724]；楼栋簇为 [−1.562542, −0.177510]。两者均以已冻结预测为条件，不是未经选择的独立显著性证明。
- F2 两个组件的误差相关约 0.98255，不能描述成“低相关融合”。实际等权融合 RMSE 低于两组件，由分量损失与交叉矩共同解释；单独 TabPFN 的 MAE 更低。
- 来源 STATUS=open 的 JRL/CRL-only 坐标仍会成为 20,557/7,153 条训练/查询记录的最近站点。只排除这些坐标时平均最近距离增加约 0.07334/0.07636 km。这是特征敏感性，不是新模型成绩，更不代表其余站点均具备完整历史日期。
