# MLP 数据分析与清洗

本分支用房屋信息预测 HDB 每月租金，单位为 SGD。EDA 的重点是区分格式问题、潜在的交易差异和时间泄漏，再通过相同验证集检验清洗是否有效。

**当前证据不支持把同一地址的所有较低租金都当作错误。** 删除明显低价后，独立 MLP 集成的 RMSE 从 471.80 小幅降到 471.26；严格只保留高价时，融合模型 RMSE 从 467.03 升到 476.25。清洗使预测更偏高，不能用“输入不再冲突”代替真实预测效果。

## 数据与实际训练范围

| 数据 | 数量 | 时间范围与用途 |
| --- | ---: | --- |
| 原始 `data/train.csv` | 150,000 | 2021-01 至 2025-03，包含训练与时间验证记录 |
| 原始 `data/test.csv` | 50,000 | 2025-03 至 2026-07，没有租金标签 |
| 当前区间模型拟合数据 | 105,837 | 2021-01 至 2023-12 |
| 独立区间校准数据 | 9,005 | 2024-01 至 2024-03 |
| 完整外层验证数据 | 35,158 | 2024-04 至 2025-03 |

原始训练文件不等于某一次模型实际拟合的数据。上述区间模型的清洗只作用于 105,837 条拟合记录，校准和外层验证均保留全部原始记录。原始 CSV 不覆盖。

已有的[完整 EDA](../reports/eda/report.md)包含分布、时间变化、空间特征和辅助表审计。这里补充与 MLP 训练直接相关的发现。

## 字段如何使用

| 字段或问题 | 处理与用途 |
| --- | --- |
| `4 room` 与 `4-room` 等写法 | 归并为一致的户型类别，避免把录入格式当成房屋差异 |
| Town、Street、Block | 规范化连接键，生成街道与楼栋 ID，使用类别嵌入；街道信息没有被忽略 |
| 面积、时间、房龄和设施信息 | 数值预处理只从拟合部分学习；网络当前使用房屋、空间与历史租金特征 |
| 地契年晚于审批年的 1 条记录 | 派生负房龄设为缺失，由训练期预处理处理；不猜测正确年份 |
| `FURNISHED=yes`、`FEE=0` | 在当前主数据中为常量，不作为主要预测输入 |
| 楼栋属性中的 `NIL`、`-1` | 视为缺失占位值；最高楼层是楼栋属性，不是出租单位所在楼层 |
| 历史租金 | 训练行使用更早月份；校准、验证和测试统一冻结到拟合截止点 |
| 股票和 COE | 曾用于独立 RNN/LSTM 实验；本次主要 MLP/TabM 集成未使用这些序列或 latent vector |

原始主表没有空值，并不代表派生特征没有缺失。未知类别、无历史交易和辅助表占位值仍需处理。静态设施快照也不完全等于交易当时的设施状态。

## 重复与相同输入不同租金

完整原始训练文件有 425 条额外完全重复记录；当前 2021—2023 拟合部分只有 26 条额外完全重复记录。不同时间范围的计数不能混用。

按规范化后的所有原始非目标字段分组，当前拟合部分有 12,763 个组对应多个不同租金，共涉及 27,906 条记录。由于缺少单位编号与合同 ID，同一楼栋、户型和面积不一定代表同一交易，不能直接将这些差异认定为录入错误。

例如，2023-06 的 1C Cantonment Road、4-room、Type S1、94㎡、地契年 2011，三条真实租金为 1,500、5,000、5,200。它们的原文件行号分别为 86944、86598、85958，均已进入实际训练部分。

训练案例见[相同输入不同租金](../reports/experiments/mlp_summary/training_cases/training_similar_inputs_different_rents.csv)。`ORIGINAL_CSV_LINE` 包含第 1 行表头，`SOURCE_ROW` 为从 0 开始的原始行索引。

## 大面积低租金的证据与解释

当前拟合部分有 231 条“面积至少 90㎡、月租不超过 S$1,300”的记录。例如 2023-11 的 25 Telok Blangah Crescent，114㎡、月租 S$600，位于原文件第 102593 行。完整清单见[训练期大面积低租金记录](../reports/experiments/mlp_summary/training_cases/training_large_flats_low_rents.csv)。这些是待核查候选，未被证实属于分租。

对后续验证期的几个案例，我们在 2026-11-03 核对了 HDB 源表：112A Depot Road 的 S$650、654B Jurong West Street 61 的 S$950/1,300，以及 Choa Chu Kang Executive 的 S$900 都在源表中存在。该核对说明低金额来自上游，不能证明申报金额准确或确定出租范围。[官方查询记录](../reports/experiments/mlp_summary/eda/official_low_rent_source_checks.json)保存了限定月份的查询结果，没有获取隐藏测试标签。

[HDB 数据说明](https://data.gov.sg/datasets/d_c9f57187485a850908655db0e8cfe651/view)指出租金由业主申报，准确性未经 HDB 核实。该源表只有月份、Town、Block、Street、户型和租金六列，无法据此核验具体单位、面积或合同条件。

完整主数据中，13,758 个重复出现的“地址＋户型”组合，其面积、房屋型号和地契年份在组内完全固定。这不证明属性填错，但说明这些字段没有区分组内具体单位。可能原因包括特殊租约、申报口径、金额错误或出租范围差异；现有数据不能确定每条记录属于哪一种。[属性一致性统计](../reports/experiments/mlp_summary/eda/enriched_attribute_consistency.json)

## 清洗规则与对照结果

规则在重训前固定，未用外层验证租金调阈值。两版都保留原模型结构、42/43/44 三个随机种子、MLP 3 个 epoch、TabM 4 个 epoch及相同预测融合方式。

**明显低价版**满足以下任一条件就从拟合数据移除：面积≥90㎡且租金≤1,300；租金低于同月同 Town 同户型中位数的 50%，且该参考组至少 20 条；或低于相同输入组最高租金的 60%，且组内至少两条。

**严格高价版**保留前两条规则，并将最后一条改为相同输入组只保留最高租金，保留并列最高值。相同输入组同时匹配月份、Town、Block、Street、户型、型号、面积和地契年，不跨年份或不同户型比较。

| 处理 | 删除数量 | 保留数量 | MLP RMSE | TabM RMSE | 融合 RMSE | 融合 MAE |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 未清洗 | 0 | 105,837 | 471.80 | 469.74 | 467.03 | 343.66 |
| 明显低价 | 1,332 | 104,505 | 471.26 | 477.72 | 468.79 | 337.00 |
| 严格高价 | 15,537 | 90,300 | 474.98 | 493.28 | 476.25 | 339.09 |

明显低价版约 55.1% 的验证记录绝对误差下降，整体 MAE 改善，但少量大误差恶化使 RMSE 上升。严格版消除了训练中相同输入的租金冲突，却将训练分布推向高价。例如 S$1,500/5,000/5,200 的组只保留 5,200，连 5,000 也被删除。

这组结果支持继续核查低价交易定义，但不支持直接把所有较低金额清除。结论限于固定模型配置，清洗后的模型尚未重新选择训练轮数或系统调参。完整[指标](../reports/experiments/mlp_summary/cleaning/comparison_metrics.csv)、[删除清单](../reports/experiments/mlp_summary/cleaning/obvious_low/removed_training_rows.csv)和[严格版清单](../reports/experiments/mlp_summary/cleaning/highest_only/removed_training_rows.csv)均保留行号与原因。

## 时间与评估边界

历史租金特征不能读取当前行真实租金、同月其他目标或未来月份标签；当前行的租金、对数租金和租金/面积不能直接作为输入。类别词表、缺失填补、缩放和数值分箱均由拟合部分学习。

区间校准、调参和最终验证承担不同角色。低租金区间只用于事后误差分析，不能用真实租金在预测时分流，也不能删除外层难例来宣称完整测试表现改善。此前已反复查看的验证月份属于开发数据；还需新的时间起点验证结论。
