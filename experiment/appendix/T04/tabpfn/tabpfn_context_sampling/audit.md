## Information policy and scope

The hidden `data/test.csv` has 50,000 rows and no rent labels. Its approval months are March 2025–July 2026. March 2025 overlaps the final labeled training month, so the Kaggle task mixes in-period interpolation and later forecasting. The present research experiment uses the fixed chronological validation split and names its policy **`historical_only`**: every selected context label is from before the earliest query month in the batch. In the earlier calibration, all eligible labels precede December 2023; in the outer split, all eligible labels precede June 2024. A separate `available_labeled_pool` policy is implemented for an in-period interpolation study, but is not used to claim chronological forecast performance. Exact duplicate transaction groups include approval month and all non-target raw fields; these are excluded from the current query/context pair. The precomputed rental-history features still use the complete eligible earlier fitting period, even when direct TabPFN context rows are sampled; this is available past information, and the feature pipeline remains identical across strategies.

## Environment and retrieval-only intervention

The machine has a desktop NVIDIA GeForce RTX 4080 with **15.99 GiB** reported CUDA device memory. Installed versions: TabPFN 9.2.0, PyTorch 2.11.0+cu128, NumPy 2.5.3, pandas 3.0.6, scikit-learn 1.9.0. The saved full-context adapter inference peaked at 8.29 GiB PyTorch allocation. The inference ablation uses a 10,000-row fixed sampled-context budget, verified by an actual short run. S0 is the existing full-context baseline; **S1 uniform at 10,000 rows is the matched-budget control** for S2/S3/S4. The context-sampler code is `analysis/experiments/tabpfn_context_sampler.py`; it reads existing latitude/longitude, month, town, flat type, area, and building age as retrieval metadata, never as additional model features. The model feature artifact, target transformation, adapter, validation row IDs, inference view count, and preprocessing seed are unchanged.

The sampler is opt-in through `analysis/compare_tabpfn_context_sampling.py`; older experiment runners are preserved. Each run saves full configuration, feature-column order, source hashes, selected row IDs, selection diagnostics, prediction rows, timing, and scores. The checked S0 baseline reuses the saved exact full-context predictions rather than spending GPU time to recompute them. No score is claimed for an experiment that has not run.
