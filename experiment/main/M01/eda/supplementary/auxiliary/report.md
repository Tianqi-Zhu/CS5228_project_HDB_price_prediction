# Auxiliary 数据 EDA 与预处理建议

本报告分析 `data/auxiliary/` 中的六个原始 CSV，并检查楼栋表与 `train.csv`、`test.csv` 的匹配情况。运行 `python -m analysis.eda.run --scope auxiliary` 可重新生成[机器可读摘要](summary.json)和三张图。实现位于 `analysis/eda/audits/auxiliary.py`；脚本只读取原始数据，所有统计与特征设想都不涉及模型训练。

## 1. 文件规模与质量

| 文件 | 记录数 | 缺失单元格 | 完全重复行 | 主要发现 |
| --- | ---: | ---: | ---: | --- |
| `sg-hdb-block.csv` | 9,464 | 0 | 0 | 285 条邮编为 `NIL`；11 条最高楼层及完工年份为 `-1`。这些是占位值，不应当作有效数值。 |
| `sg-mrt-stations.csv` | 243 | 0 | 0 | 231 条 `open`、12 条 `planned`；按经纬度只有 192 个不同地点。 |
| `sg-shopping-malls.csv` | 113 | 0 | 0 | 113 个不同名称和坐标。 |
| `sg-schools.csv` | 337 | 0 | 0 | 其中 182 条的 `MAINLEVEL_CODE` 包含 `primary` 或 `p1`；有 4 条记录与别的学校共用坐标。 |
| `sg-coe-prices.csv` | 539 | 0 | 0 | 覆盖 2021-01 至 2026-08；最后的 2026-08 仅 3 条，属于不完整月份。 |
| `sg-stock-prices.csv` | 91,642 | 510 | 0 | 77 个股票代码；85 行的六个行情字段全部缺失，另有 2,623 行交易量为 0、72 行 OHLC 范围异常。 |

四个地理文件的经纬度均可解析，且没有超出合法经纬度范围的值。以上“缺失单元格”只统计 CSV 读取后的空值，不包含 `NIL` 或 `-1` 这样的占位值。

## 2. 楼栋地址匹配

对 `TOWN + BLOCK + STREET` 做大小写、首尾空格及连续空白规范化后，楼栋表没有重复键。以这个组合键进行多对一匹配：

| 主数据 | 记录数 | 匹配成功 | 匹配率 | 邮编为 `NIL` | 最高楼层／完工年份为 `-1` |
| --- | ---: | ---: | ---: | ---: | ---: |
| `train.csv` | 150,000 | 150,000 | 100% | 5,259 | 159 |
| `test.csv` | 50,000 | 50,000 | 100% | 1,739 | 0 |

因此，楼栋坐标适合作为第一批辅助特征；邮编、最高楼层和完工年份需要单独处理占位值。楼栋表中的完工年份有效值为 1949–2021，最高楼层有效值为 2–50。匹配率高只说明地址连接可行，尚不能证明新特征能降低租金预测误差。

在已知完工年份的记录中，没有出现“完工年份晚于租金审批年份”的情况。训练集有 5,865 条、测试集有 1,932 条记录，其完工年份与 `LEASE_COMMENCE_DATE` 相差超过 5 年。因此，这两个年份不能简单互换；应分别检查派生楼龄的效果。除 `NIL` 外，楼栋表的邮编都是六位数字。

## 3. 地点分布与距离

[地点位置图](01_auxiliary_locations.png)展示 9,464 栋 HDB 与 MRT、商场、小学的经纬度分布。[最近设施距离图](02_nearest_distances.png)按每栋楼计算到最近地点的球面直线距离；它不是步行路程。

| 最近地点 | 用于距离计算的不同地点数 | 中位距离 | 90 分位距离 | 1 km 内的楼栋占比 |
| --- | ---: | ---: | ---: | ---: |
| 当前标记为 `open` 的 MRT | 192 | 0.568 km | 1.039 km | 88.46% |
| 商场 | 113 | 0.747 km | 1.522 km | 68.97% |
| 小学（含 `p1` 的混合学段学校） | 180 | 0.366 km | 0.710 km | 97.23% |

MRT 文件的 243 行代表线路／车站代码，不等于 243 个独立地点；12 条 `planned` 记录的坐标都与某条 `open` 记录相同。计算最近站距离或附近站点数时应按实际地点去重，避免换乘站被重复计数。当前文件没有开通日期，不能根据现在的 `STATUS` 确定一座车站在 2021–2025 年是否已经运营。商场和学校文件也没有历史营业／开办日期。因此，上表只能描述文件的**当前地点快照**，不能直接解释历史审批时的可达性。

## 4. 经济数据覆盖

[月度覆盖图](03_economic_coverage.png)展示 COE 记录数与有有效行情的股票代码数，虚线为训练集最后一个月 2025-03。

- COE 的 `YEAR + MONTH` 均可解析，2021-01 至 2026-08 的 68 个月连续覆盖；类别为 `a`、`b`、`c`、`e`，通常每类每月两轮。`YEAR + MONTH + CATEGORY + ROUND` 没有重复。`QUOTA_PREMIUM`、`PREVAILING_QUOTA_PREMIUM`、`QUOTA` 和 `BIDS_RECEIVED` 清理 `$`／千位逗号后都能转换为数字；`QUOTA_PREMIUM` 范围为 S$35,900–S$158,004。类别 `e` 的 134 条 `PREVAILING_QUOTA_PREMIUM` 均为真实的 `$0` 字段值，不能擅自改成缺失。2026-08 仅有 3 条记录，不能当作完整月份汇总。
- 股票日期均可解析，覆盖 2021-01 至 2026-07 的 67 个月且中间无整月缺口。`SYMBOL + DATE` 没有重复，但每个代码只有 113–1,403 行，月度有有效报价的股票数从 53 逐步增加到 77。85 行的 OHLC、调整后收盘价和交易量同时缺失，不应将它们当作 0 元行情；2,623 行交易量为 0，也不宜直接当作缺失。调整后收盘价没有非正值。
- 77 个股票代码中，43 个以 `.SI` 结尾、4 个以 `.HK` 结尾、1 个以 `.AS` 结尾、29 个没有交易所后缀。不同代码的调整后收盘价范围为 0.092–6,544.8，不能直接平均这些价格水平。另有 72 行开盘价或收盘价不在当日 `[LOW, HIGH]` 范围内，集中于 4 个 `.HK` 代码；使用 OHLC 特征前应核查或过滤这些行。

经济指标还取决于预测发生的时间。如果模型在**每个审批月份**估计租金，可以考虑该月之前已公布的指标。如果要求在训练截止日（2025-03）**一次性预测此后所有月份**，则之后的 COE 与股价在预测时尚不可知；即使辅助 CSV 收录了这些数值，也不能用它们来声称模型完成了严格的前瞻预测。后续实验必须先明确场景，并在验证和最终预测中采用同一规则。

## 5. 建议的预处理与实验顺序

| 数据 | 建议处理 | 主要风险／验证办法 |
| --- | --- | --- |
| 楼栋表 | 用规范化后的 `TOWN + BLOCK + STREET` 左连接主数据。`POSTAL_CODE` 保留为字符串，将 `NIL` 记为缺失；`MAX_FLOOR` 和 `YEAR_COMPLETED` 中的 `-1` 记为缺失。可以比较经纬度、Subzone、最高楼层以及“审批年份减完工年份”。 | 不覆盖原始列；训练期内拟合缺失值处理。检查完工年份是否晚于审批年份，并比较新楼龄与 `LEASE_COMMENCE_DATE` 派生楼龄是否重复。 |
| MRT | 从匹配的楼栋坐标计算最近站直线距离、1 km 内独立地点数。先按坐标／站名核对并去重。 | `STATUS` 是当前状态；若要称为“审批时已运营”，须补充开通时间。否则仅把距离解释为当前地理位置的代理特征，并在报告中标明限制。 |
| 商场、学校 | 分别计算最近距离与邻近数量；学校先按 `MAINLEVEL_CODE` 选择小学及含小学的混合学段。 | 共址学校的“学校数量”与“地点数量”定义不同；先固定定义。缺少历史开办日期时，不能断言它们在过去已存在。 |
| COE | 保留类别与轮次，解析货币、配额和投标数字；按明确规则生成每类别月度值，再根据预测时点滞后连接审批日期。 | 不同类别不能无说明地求平均；类别 `e` 的现有 `$0` 保留原义。不能使用预测时尚未公布的价格，排除／标记不完整的 2026-08。 |
| 股票 | 过滤行情全空行；按 `SYMBOL` 用 `ADJUSTED_CLOSE` 计算收益率，再聚合成少量滞后月度指标。 | 股票覆盖年限、交易市场及价格尺度不同；先检查异常 OHLC 与零交易量，避免直接平均不同股票的价格水平。不能把空行情填 0，也不能使用预测时尚未出现的行情。 |

下一步建议先比较当前模型与“当前模型 + 楼栋属性”；再分别加入 MRT、商场／学校距离，最后尝试 COE 和股票指标。每次使用相同的时间验证划分，记录连接成功率、RMSE、MAE、平均偏差和逐月误差。若要优化真正的未来预测，还应增加更长的时间验证窗口。现阶段的 EDA 没有训练辅助数据模型，也没有验证这些特征是否能改善分数。
